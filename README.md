# Learning to Hear While Walking Project Page

Static project page for EgoGraph and Transfer-DiT.

Directory roles:

- the private experiment repository: experiment data, page-builder code, and
  configuration source of truth
- this repository: generated publication assets and the GitHub Pages site

Public page:

https://blind-review-demo.github.io/EgoSep-Project/

Open `index.html` through GitHub Pages or a local static server.

```bash
python -m http.server 8000
```

Then open:

```text
http://127.0.0.1:8000/
```
